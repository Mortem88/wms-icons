Состав набора и имена файлов

Имя файла: <группа>-<объект>-<состояние>_<размер>.png. Вектор — тот же файл без суффикса размера, в .svg.

Источник — вектор (SVG, 128×128), растеризация в PNG на каждый целевой размер. Набор поставляется двумя палитрами и в двух форматах: PNG 14–64 px с альфа-каналом и SVG для любого размера. Слабое место набора на 14–16 px — стеллаж («Отбирается» / «Отобрано»): деталей больше, чем пикселей, состояние там читается цветом.
